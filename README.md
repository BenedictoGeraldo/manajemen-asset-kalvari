# Projek Pelita - Manajemen Aset Kalvari

Aplikasi manajemen aset berbasis web untuk Paroki Kalvari Lubang Buaya.

## Fitur Utama
- Manajemen Aset Kolektif.
- Manajemen Master Data (Kategori, Lokasi, Kondisi, Pengelola).
- Transaksi Aset (Peminjaman, Pemeliharaan, Mutasi, Pemusnahan).
- Laporan Aset dan Cetak QR Code.
- Manajemen Pengguna dan Hak Akses Berbasis Role.

## Teknologi
- Framework: Laravel 10
- Frontend: Tailwind CSS & Alpine.js (via Laravel Vite)
- Database: MySQL 8.0
- Lingkungan: Docker (Laravel Sail)

## Instalasi
Silakan ikuti panduan langkah demi langkah di file [INSTALLATION.md](INSTALLATION.md).

## Lisensi
Projek ini dibuat untuk keperluan internal Paroki Kalvari Lubang Buaya.
